# pathplanner_mock_tools

Existing pathplanning mock implementations relocated here without algorithm changes.

Installed executables: `mock_rover_sim`, `mock_perception`, `drop_stone`, `algo_node`, `mock_base`, `generate_benchmark_maps`.

The old `global_path_benchmarking` executable names/imports remain compatibility entry points.
Both names start the same implementation; do not run both together.

These fixtures are not validated mission truth. The mock-development agent owns
further mock behavior and interface improvements.
