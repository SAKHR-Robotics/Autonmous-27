Path Planning Module

System Architecture, Inter-Module Interface Specifications (I/O), and Integration Reference for the Autonomous Rover.

1. Completed & Functional Modules

Smac Hybrid A* Global Planner

Computes kinematically feasible global routes considering turning constraints and footprint.

  • Plugin: nav2_smac_planner::SmacPlannerHybrid
  • Kinematic Model: Reeds-Shepp (Forward/Reverse)
  • Min Turn Radius: 0.8 meters
  • Search Frequency: 20.0 Hz

MPPI Local Controller

High-speed sampling predictive controller generating optimal, collision-free velocity commands.

  • Plugin: nav2_mppi_controller::MPPIController
  • Batch Size: 2000 rollouts / 56 time steps
  • Velocity Envelope: Vx: [-0.5, 1.0] m/s | Wz: 1.0 rad/s
  • Active Critics: PathAlign, Goal, Constraint, PreferForward

Dual-Layer Costmaps

Synchronous global environment mapping alongside dynamic rolling local window.

  • Global Costmap: Static Layer + Inflation Layer
  • Local Costmap: 10x10m Rolling Window (0.05m res)
  • Reliability: always_send_full_costmap: true
  • Obstacles: Real-time 3D PointCloud2 integration

Perception Bridge Node

High-efficiency C++ node converting custom camera obstacle arrays into standard point clouds.

  • Executable: costmap_bridge_node (C++17)
  • Input Topic: /terrain/obstacle_features
  • Output Topic: /bridge/pointcloud (PointCloud2)
  • Processing: Zero-copy centroid parsing

6. Dynamic Obstacle Avoidance & Replanning Flow

1. High-Frequency Local Swerving (20 Hz)

When the RealSense camera detects a localized rock, the local_costmap marks it. MPPI evaluates 2,000 trajectory rollouts per cycle. ConstraintCritic prunes colliding curves while PathAlignCritic selects a collision-free path that swerves around the rock and steers smoothly back onto /plan without stopping.

2. Local Controller Failure (Passage Blocked)

If a boulder completely blocks a narrow passage or crater rim, all 2,000 MPPI rollouts result in collision. MPPI halts the rover (0 m/s) to prevent a crash and reports NO_VALID_TRAJECTORY back to the Behavior Tree. MPPI does not communicate with the global planner directly.

3. Global Detour Generation

The Behavior Tree catches MPPI's failure signal and triggers the Smac Hybrid A* Global Planner. Because the global costmap includes an obstacle_layer, the planner recognizes the blockage and computes a brand new macro route (e.g. detour around the entire hill/canyon) and feeds it to MPPI.

4. Nav2 Recovery Fallbacks

If the rover is boxed in and even the Global Planner fails: the BT executes recovery plugins sequentially: (1) Costmap Clear to flush sensor ghosts, (2) BackUp to reverse 0.8m out of the bottleneck, and (3) Spin to refresh 360° terrain visibility before retrying.
