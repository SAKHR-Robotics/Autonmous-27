Wheel Odometry Pre-Processor
encoder_ticks_to_odom.py
Pre-Processing
  • Reads raw wheel encoder rotation tick counts from rover wheel drive encoders.
  • Calculates differential drive linear velocity ($v_x, v_y$) and angular velocity ($\omega_z$) based on rover chassis kinematics.
  • Outputs raw wheel odometry twist data for slip filtering and EKF state estimation.
  • /wheel/odom_raw nav_msgs/msg/Odometry
  • /wheel/ticks Raw Encoders / std_msgs
Heuristic Slip Checker
heuristic_slip_checker.py
Pre-Processing Filter
  • Detects wheel slippage in loose sand by comparing wheel linear velocity ($V_{wheels}$) vs IMU linear acceleration ($V_{imu}$) and wheel turning rate ($\omega_{wheel}$) vs IMU $Z$-axis gyro ($\omega_{imu}$).
  • Slip Rule: Flagged if $|V_{wheels} - V_{imu}| > 0.15\text{ m/s}$ or angular rate disagrees.
  • Dynamic Covariance Reaction: Dynamically inflates wheel process noise/covariance on `/wheel/odom_raw`, forcing EKF to ignore slipping wheels and rely on IMU + Visual SLAM.
  • /wheel/odom_raw nav_msgs/msg/Odometry (Updated Covariance)
  • /wheel/odom_raw nav_msgs/msg/Odometry
  • /imu/data sensor_msgs/msg/Imu
Depth Post-Processing Filter
vision_helper.launch.py
Vision Filter
  • Cleans raw Intel RealSense D435 depth images to fix outdoor IR interference and sunlight holes.
  • Decimation: Reduces depth resolution to save Jetson compute.
  • Spatial Filter: Edge-preserving smoothing of high-frequency noise spikes.
  • Temporal Filter: Averages consecutive frames to eliminate black pixel jitter.
  • Hole-Filling Filter: Extrapolates gaps from neighboring pixels.
  • Max Range Clip: Truncates depth $> 4.0\text{m}$ to remove noisy far-field data.
  • /camera/depth/filtered sensor_msgs/msg/Image
  • /camera/depth/image_rect_raw sensor_msgs/msg/Image
EKF Node (robot_localization)
config/ekf.yaml & launch/ekf.launch.py
Local State Estimator
  • Fuses linear velocity ($X, Y$) from wheel odometry (`/wheel/odom_raw`) and orientation (Roll, Pitch, Yaw) + angular velocity from IMU (`/imu/data`).
  • Runs at high frequency (100 Hz) with zero latency and no coordinate jumps.
  • Provides continuous local state estimation for the MPPI motion controller.
  • Configured with world_frame: odom and two_d_mode: false for 3D slopes.
  • /odometry/filtered nav_msgs/msg/Odometry (100 Hz)
  • TF: odom → base_link Transform Frame (100 Hz)
  • /wheel/odom_raw nav_msgs/msg/Odometry
  • /imu/data sensor_msgs/msg/Imu
RTAB-Map Visual SLAM
config/rtabmap.yaml & rtabmap.launch.py
Global SLAM Backend
  • Extracts visual features (FAST/GFTT) from RGB & filtered depth streams to build visual 3D memory map.
  • Performs loop-closure detection and integrates 6-DOF ArUco landmark poses (`/perception/aruco_pose`) as global constraints.
  • Calculates global drift offset between real world map frame and local odometry frame.
  • Broadcasts global transform correction map → odom (1–5 Hz) without jerking local wheel control loops.
  • /map nav_msgs/msg/OccupancyGrid
  • TF: map → odom Transform Frame (1–5 Hz)
  • /rtabmap/grid_map nav_msgs/msg/OccupancyGrid
  • /camera/color/image_raw sensor_msgs/msg/Image
  • /camera/depth/filtered sensor_msgs/msg/Image
  • /odometry/filtered nav_msgs/msg/Odometry
  • /perception/aruco_pose geometry_msgs/msg/PoseStamped
ArUco Detector Node
aruco_detector_node.py
Landmark Perception
  • Processes raw camera color stream `/camera/color/image_raw` using OpenCV (`cv2.aruco.detectMarkers()`).
  • Solves Perspective-n-Point math (`cv2.solvePnP()`) using camera calibration matrix to compute exact 3D pose of detected markers.
  • Publishes 6-DOF marker coordinates relative to camera frame as absolute landmark correction inputs for RTAB-Map.
  • /perception/aruco_pose geometry_msgs/msg/PoseStamped
  • /camera/color/image_raw sensor_msgs/msg/Image
  • /camera/camera_info sensor_msgs/msg/CameraInfo
Nav2 Costmap 2D Server
config/costmap_params.yaml & costmap.launch.py
Navigation Costmap
  • Creates layered 2D occupancy grid map for global and local path planning.
  • Static Layer: Subscribes to static SLAM map `/map` from RTAB-Map.
  • Obstacle Layer: Subscribes to `/perception/obstacles_only` (rock point clouds/bounding boxes).
  • Inflation Layer: Inflates rock obstacle boundaries with safety cost gradients according to rover footprint size.
  • /global_costmap/costmap nav_msgs/msg/OccupancyGrid
  • /local_costmap/costmap nav_msgs/msg/OccupancyGrid
  • /map nav_msgs/msg/OccupancyGrid
  • /perception/obstacles_only sensor_msgs/msg/PointCloud2
  • TF: map → base_link Full TF Chain Lookup
Static Transform Broadcaster
launch/static_transforms.launch.py
TF Infrastructure
  • Publishes fixed physical geometric transform offsets between chassis and hardware sensors.
  • Establishes accurate physical spatial relations between robot center `base_link`, IMU (`imu_link`), camera (`camera_link`), and optical frame (`camera_depth_optical_frame`).
  • TF: base_link → camera_link Static Transform
  • TF: base_link → imu_link Static Transform
  • TF: camera_link → optical_frame Static Transform
  • None Broadcaster (Static TF)
